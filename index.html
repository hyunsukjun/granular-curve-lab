Read Position · 0–100% of Source WindowChoose where grains start within the selected source window. It does not set output playback time.
Spread · 0–100%Randomize grain read positions around Read Position within the selected source window.
Grain Size · 5–1000 msSet the requested grain length. The actual length can be shorter to stay inside Source Window at the current pitch.
Density · 1–80 grains/sSet the requested number of new grains per second. Preview uses up to 64 voices, reduced to 32 at high density/size; Render uses up to 64.
Pitch Low · −24 to +24 semitonesSet one end of the random grain pitch range. If Low crosses High, the bounds are reordered.
Pitch High · −24 to +24 semitonesSet the other end of the random grain pitch range. 12 semitones = one octave; pitch also changes grain read speed.
