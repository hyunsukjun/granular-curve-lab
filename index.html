Files & export
Input
WAV, MP3 recommended.
AIFF
Mono/stereo 16/24-bit PCM (8–192 kHz), converted locally on import. AIFF-C is not supported.
AIFF limits
128 MiB file / converted WAV; 192 MiB decoded audio. Other formats depend on browser memory.
Output
1–600 s synthesis · 2 / 4 / 8 channels · 48 kHz / 24-bit WAV.

Grains use the first input channel. Short excerpts recommended. Use one Lab at a time for heavy processing.

Available duration and channel settings do not imply that every combination has been validated. Stability at 600 s / 8 channels has not been verified. Long multichannel exports can use substantial memory; try a short excerpt first. Preview and offline render use different processing limits and may differ in sound and level.

Current verification covers selected cases on macOS 27.0.1 with Brave 156.1.98.60; it does not certify all browsers, devices or settings.

Read Position · 0–100% of Source WindowChoose where grains start within the selected source window. It does not set output playback time.
Spread · 0–100%Randomize grain read positions around Read Position within the selected source window.
Grain Size · 5–1000 msSet the requested grain length. The actual length can be shorter to stay inside Source Window at the current pitch.
Density · 1–80 grains/sSet the requested number of new grains per second. Preview limits active grains to 64, reduced to 32 at high density/size, with brief fade-out tails. Offline render processes all scheduled grains.
Pitch Low · −24 to +24 semitonesSet one end of the random grain pitch range. If Low crosses High, the bounds are reordered.
Pitch High · −24 to +24 semitonesSet the other end of the random grain pitch range. 12 semitones = one octave; pitch also changes grain read speed.
